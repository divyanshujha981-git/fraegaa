# 🎮 FraeGaa

**FraeGaa** is a gaming website built with modern web technologies, designed to provide a smooth and engaging gaming experience.

## 🚀 Tech Stack

- **Frontend:** React.js + Vite
- **Database:** Firebase Firestore
- **Deployment:** Vercel

## ✨ Features

- 🎮 Gaming-focused web experience
- ⚡ Fast development and performance with Vite
- 🔥 Cloud database integration using Firebase Firestore
- 🌐 Web deployment and hosting through Vercel
- 📱 Responsive interface for different screen sizes

## 🛠️ Installation and Setup

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)

### 1. Clone the repository

```bash
git clone https://github.com/divyanshujha981-git/gaming-friend
```

### 2. Navigate to the project directory

```bash
cd gaming-friend
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.

## 🔥 Firebase Configuration

FraeGaa uses Firebase Firestore for database functionality.

To configure Firebase:

1. Create a project in the [Firebase Console](https://console.firebase.google.com/).
2. Enable Cloud Firestore.
3. Register your web application.
4. Configure your Firebase credentials in the project according to your application's setup.
5. Set up appropriate Firestore security rules to protect your data.

If your project uses environment variables, add the required Firebase configuration to a `.env` file and ensure that sensitive configuration is not committed accidentally.

## 🌐 Deployment

FraeGaa is deployed using [Vercel](https://vercel.com/).

To deploy your own version:

1. Push your project to GitHub.
2. Import the repository into Vercel.
3. Configure the required environment variables.
4. Deploy the project.

Vercel can automatically rebuild and deploy the website when changes are pushed to the connected repository.
